# Blinker

軽量・高速起動の Windows 用画像ビューア。C++20 / Win32 API / Direct2D / WIC 製、外部依存ゼロの単一 exe。

## 特徴

- **軽快**: 数百 KB の単一実行ファイル。起動即表示、フォルダ内の画像を先読みして瞬時に遷移
- **キーボード中心**: すべての操作にショートカットキー。`blinker.ini` で自由に変更可能
- **対応形式**: JPEG / PNG / BMP / GIF / TIFF / ICO / JXR。Windows 11 なら HEIC / WebP / AVIF も(OS コーデック経由)
- **アニメーションと多ページ**: アニメーション GIF を再生(`Space` で再生 / 一時停止)。
  多ページ TIFF と ICO の複数サイズは `Shift+←` / `Shift+→` でページ送り(ICO は最大サイズから開く)
- **文字認識 (OCR)**: 画像内の文字を読み取ってクリップボードへ。Windows 内蔵の認識器を使うので追加インストール不要
- **拡張しやすい設計**: プラットフォーム非依存の core 層と Win32 実装層を分離(詳細は [docs/architecture.md](docs/architecture.md))

## ビルド

必要環境: Visual Studio 2022(「C++ によるデスクトップ開発」ワークロード)

```powershell
# "Developer PowerShell for VS 2022" で実行
cmake --preset release
cmake --build --preset release
# 生成物: build/release/blinker.exe

# テスト
ctest --preset release
```

## 使い方

```
blinker.exe <画像ファイル | フォルダ>
```

画像ファイルへのドラッグ&ドロップ、「プログラムから開く」にも対応。

### デフォルトキーバインド

この表と同じものを **アプリ内で `F1`** を押して開ける(サイドバーに操作一覧が出る)。
中身は実際のキーバインドから作られるので、`blinker.ini` で変更したキーがそのまま出る。
何も割り当てられていないキーを押すと、ステータスバーに `F1` の案内が出る。

| ウィンドウにフィット / 等倍 | `0` / `1` |
| スクロール(パン) | `Ctrl+矢印`、マウス左ドラッグ(入れ替え可) |
| 回転(表示のみ) | `R`(右90°)/ `Shift+R`(左90°) |
| フルスクリーン | `F11` `Enter` |
| ファイルを開く | `Ctrl+O` |
| 画像をクリップボードへコピー | `Ctrl+C` |

| クリップボードの画像を貼り付け | `Ctrl+V` |
| 上書き保存(確認あり) | `Ctrl+S` |

### 画像編集

マウスの**右ドラッグ**は、あらかじめ選んである**現在のツール**をその場で実行する
(ドラッグ中は結果そのものがプレビューされる)。現在のツールはステータスバーに出る。
左右のボタンは入れ替えられる(後述の `[mouse] swap_buttons`)。

- **矩形 / 楕円 / 矢印 / 直線**: ドラッグした範囲に描く。既定は矩形
- **ペン (手書き)**: ドラッグの軌跡をそのまま線にする。取りこぼした通過点は
  曲線でつないで滑らかに描く
- **マーカー**: 手書きの半透明・太線版(蛍光ペン)。線幅は「線の太さ」の 4 倍、
  不透明度は 40%。線が自分と重なっても濃くならない
- **連番マーカー**: 数字入りの丸を置く。番号は 1 から自動で増える(手順の説明に使う)。
  ドラッグの大きさが円の大きさになり、`Shift` なしでも必ず真円になる
- **テキスト**: ドラッグした範囲を空のテキストボックスにして、その場で入力を始める
  (`Enter` で改行できる複数行対応。枠の幅で自動折り返し)
- **トリミング**: 選択領域で画像を切り出す(図形・テキストは位置を保ったまま残る)。
  一度きりの操作なので、実行すると直前の図形ツールへ自動で戻る
- **文字認識 (OCR)**: 選択領域の文字を読み取ってクリップボードへコピーする。
  画像は変えないので、続けて別の範囲を読み取れる(後述)

`Shift` を押しながら右ドラッグすると範囲が正方形になり、正方形の矩形・真円を描ける
(テキストボックスとトリミングにも効く)。一辺は縦横の移動量の小さいほうに合わせるので、
画像の端まで引いても範囲は画像内に収まる。

**直線・矢印**の `Shift` は正方形化ではなく向きのスナップで、始点から見て一番近い
水平・垂直・45 度の向きへ寄せる。まっすぐな横線・縦線はこれで引ける。ドラッグ中に
`Shift` を押したり離したりすればプレビューがその場で切り替わるので、引き終える直前に
押さえるだけでもよい。描いたあとに端点のハンドルを `Shift` を押しながらドラッグしても
同じように揃う(既に傾けてある図形でも、画面上の見た目が水平・垂直になる)。

**ペン・マーカー**の `Shift` も同じ向きのスナップで、押している間はまっすぐな線になる。
起点は `Shift` を押した瞬間の位置なので、途中まで手書きしてから押さえればそこから先だけが
まっすぐになり、離せばまた自由に描ける(押す前に描いた部分は消えない)。ドラッグの
最初から押していれば、始点から終点までまっすぐな 1 本の線が引ける。

ツールの切り替えは、**何もない場所での右クリック**(ドラッグなし)で開くメニューから行う。
同じメニューで新規作成時の既定値も変えられ、設定を選んだ後はメニューが再表示されるので、
設定を整えてからツールを選べる:

- **線の太さ / 文字サイズ**: プリセットから選択(画面上の見た目基準。ズーム率に応じて
  画像へ換算される)
- **フォント**: テキストの書体(游ゴシック / メイリオ / MS 明朝 など)。
  インストールされているものだけが候補に出る。既定は和欧文とも游ゴシック
- **色の変更...**: Windows 標準の色ダイアログで自由に指定

起動時のツールは `blinker.ini` の `[edit] tool`(`crop` / `rect` / `ellipse` / `arrow` /
`line` / `pen` / `marker` / `number` / `text`)で指定できる。ツールはキーにも割り当てられる
(`[keys]` で `tool_rect` `tool_pen` など。既定のキーは割り当てていない)。

追加した図形・テキストはオブジェクトとして残り、あとから編集できる:

- **左クリック**で選択(破線の枠とハンドルが出る)。**左ドラッグ**で移動
  (`[mouse] swap_buttons` で左右を入れ替えても、掴む操作は常に左のまま)
- 枠の四隅・辺の**サイズ変更ハンドル**をドラッグして拡大・縮小(`Shift` で縦横比を維持)。
  直線・矢印は端点をドラッグ。テキストは幅を変えると折り返し直され、高さは内容に合わせて
  自動で決まる(文字サイズはメニューで変更)
- 枠の上に出る**回転ハンドル**をドラッグすると自由な角度に回転(`Shift` で15°刻み)
- オブジェクトの上での**右クリック**でオブジェクトメニューが開き、回転角度(プリセット)・
  線の太さ・文字サイズ・フォント・色の変更・削除ができる。手書きは線の不透明度
  (ペンとマーカーの行き来)、連番マーカーは番号の振り直しもここから
- テキストは**ダブルクリック**(またはオブジェクトメニュー)で内容を再編集できる
- テキストを選択中の `Ctrl+B` はテキスト全体の太字を切り替える(サイドバーの開閉より
  優先される)。編集中の `Ctrl+B` が選択範囲だけに効くのと同じ規則で、
  全体が太字なら解除される
- `Delete` で選択中のオブジェクトを削除。`Esc` で選択解除

編集は `Ctrl+Z` で1段階ずつ取り消せ、`Ctrl+Y`(または `Shift+Ctrl+Z`)でやり直せる
(履歴はそれぞれ直近10回。取り消したあとに新しい編集をすると、やり直し先は捨てられる)。図形・テキストは画像へは
焼き込まれず、`Ctrl+S` の保存や `Ctrl+C` のコピー時に合成される。元ファイルが自動で
書き換わることはなく、別の画像へ移動すると未保存の編集は破棄される。
線の太さ・文字サイズ・フォント・色の初期値は `blinker.ini` の `[edit]` セクションで
変更できる。

### 文字認識 (OCR)

`Ctrl+T` で、表示中の画像の文字を読み取ってクリップボードへコピーする。
一部だけ読みたいときは、ツールメニュー(何もない場所で右クリック)で
**文字認識**を選び、読みたい範囲を右ドラッグする。トリミングと違って画像は
変わらないので、続けて別の範囲を読み取れる。

認識には Windows 内蔵の文字認識機能を使うため、追加のインストールは不要。
ただし言語ごとの認識器がシステムに入っている必要がある(**設定 → 時刻と言語 →
言語と地域** で、言語の「オプション」から追加できる)。入っていない場合は、
使える言語の一覧がステータスバーに出る。使う言語は `blinker.ini` の
`[ocr] language` で固定できる(既定は表示言語から自動選択)。

日本語は語の区切りに空白が入って返るため、CJK 文字に挟まれた空白は取り除いて
コピーする(「これ は テスト」→「これはテスト」)。和欧混在の区切りは残る。

小さい文字は認識精度が落ちるため、1 回読んだ結果の行の高さが小さければ
自動で拡大して読み直す(実測で平均精度 71.5% → 84.2%)。この読み直しが走るのは
文字が小さいときだけで、大きい文字は 1 回で終わる。

認識は別スレッドで走るので、大きな画像でも操作が固まることはない
(1 枚あたり 100ms 未満)。縦書き・手書きは認識器そのものが対応しておらず、
前処理では改善しない。

### 印刷

`Ctrl+P` で Windows の印刷ダイアログが開き、選んだプリンタへ 1 ページで刷る。
プリンタ・用紙・向き・部数はダイアログで選ぶ。**刷られるのは画面で見えているとおり**で、
描いた図形・テキストと表示回転 (`R`) はそのまま紙にも出る(元のファイルは変わらない)。

画像は用紙の印刷可能領域に、縦横比を保って最大の大きさで中央に配置する。用紙より
小さい画像も拡大する(600dpi のプリンタで原寸に刷ると切手ほどの大きさにしかならない)。
横長の画像を縦向きの用紙に刷るときのように、90 度回した方が大きく刷れる場合は自動で
回す。余白 (`[print] margin_mm`、既定 10mm) と自動回転 (`auto_rotate`) は
`blinker.ini` で変えられる。

### 設定

`blinker.exe` と同じフォルダに `blinker.ini` を置くと、キーバインドや背景色、
タイトルバーのテーマ(OS設定追従 / ダーク / ライト)を変更できる。

マウスの左右のボタンは `[mouse] swap_buttons = true` で入れ替えられる。
入れ替わるのは「**パン**(スクロール)」と「**編集ドラッグ**(現在のツールの実行)」の
2 つだけで、左ドラッグで図形を描き、右ドラッグでパンするようになる。

**図形・テキストを掴む操作**(選択・移動・回転・サイズ変更)は入れ替えの対象外で、
入れ替えても**常に左クリック**。**メニューも対象外**で、ツール切り替え・オブジェクト・
書式のどのメニューも常に右クリック(ドラッグなし)で開く(サイドバーの項目クリックも
常に左)。入れ替え時の左ボタンは「図形の上なら選択、そうでなければ描画」になるため、
既存の図形の上から新しい図形を描き始めることはできない(何もない場所から始める)。

ポインタを**画面の左右の端**に近づけると、前後の画像へ移るボタン(◀ ▶)が画像の上に
出る(ボタンの上でクリックしたときだけ効く)。邪魔なら `[view] nav_arrows = false` で消せる。

**中ボタン・サイドボタン・ホイール・ダブルクリック**には `[mouse]` でキーと同じ
コマンドを割り当てられる(既定は前後の画像)。ホイールのズームは割り当てではなく
「割り当てのないホイールの既定動作」なので、`next = WheelDown` のように素のホイールを
埋めれば `Ctrl+ホイール` がズームになる(モードを切り替える設定は無い)。

`F1` の操作一覧に出るキー表記は、そのまま `[keys]` に書ける形式になっている。
書式は [docs/blinker.ini.example](docs/blinker.ini.example) を参照。
